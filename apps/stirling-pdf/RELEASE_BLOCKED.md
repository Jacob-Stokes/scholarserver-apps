# Stirling PDF draft — not a release

Do not install, build images, publish a catalog entry or deploy this candidate.
The manifest deliberately lives in `development`, outside release discovery.

- v2.14.3 native MCP is under the Stirling PDF User License, not blanket MIT.
  Confirm production, redistribution and managed-hosting rights before any image use.
- Image references are deliberately invalid placeholders. Resolve licensed edition,
  release-to-image provenance, immutable digest and native architecture support.
- Native MCP protocol/authentication and the exact two-operation allowlist require
  real tests. This source adapter is not a proven Gateway connection.
- Verify read-only/non-root startup, writable directories, health checks, native UI
  same-origin access routing, credentials and account lifecycle on the final image.
- Prove preserved originals, real PDF output, signed/encrypted documents, deadlines,
  unknown outcome reconciliation, parser isolation and backup/restore.
- A single instance is one trusted workspace, not per-human authorization. Dedicated
  upstream credentials and instance-isolated storage are mandatory. Multi-user exposure
  requires a separately reviewed identity model; no cross-account promise is made.

See DEVELOPMENT_NOTES.md for evidence and deliberately missing functionality.
